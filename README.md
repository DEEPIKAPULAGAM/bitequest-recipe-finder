# BiteQuest – Recipe Finder

BiteQuest is a web application that helps users find recipes based on ingredients they have at home.

Users can type ingredients like chicken, egg, or pasta and the website will show recipes using those ingredients.

## Features
- Search recipes by ingredient
- View recipe cards with images
- Click a recipe to see ingredients and instructions
- Links to cooking videos

## Technologies Used
HTML
CSS
JavaScript
TheMealDB API
